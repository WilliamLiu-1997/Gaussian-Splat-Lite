# Security policy

## Supported versions

Security fixes are provided for the latest published version of
`gaussian-splat-lite`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it
privately to William Liu at <lyz15972107087@gmail.com> with:

- the affected version and environment;
- steps to reproduce or a proof of concept;
- the expected impact; and
- any suggested mitigation, if available.

You should receive an acknowledgement within seven days. Please allow time for
investigation and a coordinated release before public disclosure.
